# 기본형 인수 기록

2026-11-20, TypeScript/Vite 브라우저 앱. 적용한 운영 모드는 pages-only다. 사용 중인 외부 조회는 Overpass로 제한한다. 네이버와 Juso는 현재 운영 키가 없다. 네이버 시험 Application이 준비되면 Geocoding 100/일·1,000/월, Dynamic Map 200/일·2,000/월을 시범값으로 검토하고, 콘솔이 지원하는 단위와 무료 제공량을 확인해 설정한다. Static Map은 끈다. 초과 사용 불허, 알림 수신, 낮은 시험 한도의 실제 거절 응답, 운영 중지·키 교체·재개를 기록한 뒤 선택 기능을 활성화한다.

| 대상 | 증거 및 범위 |
| --- | --- |
| 장소와 입구 | 다산74는 공식 주소와 OSM 단지를 식별했다. 자료는 data/dasan74.json에 있다. 보행·차량 입구는 미확인이다. 사용자가 위치를 대조하면 시점·출처·방법과 확인 항목을 기록한다. |
| 변환·출력 | 연결 노드 고정, 다산74 라벨과 도로 충돌 검사. Chrome에서 샘플과 평가용 주소 10곳의 출력물을 실제로 읽었다. 상세 수치는 output.md와 evaluation.md에 있다. |
| C01~03·05·07·08 | 고정 시각 경계, 다른 장소 키, 이전 성공본 보존, 가져온 자료의 최신성·위치 검수 초기화를 tests/cache.test.ts에서 검사한다. |
| S01 | 공개할 파일을 선별하고 개인 이름·로컬 사용자 경로·토큰 패턴을 검사한다. 암호 원문은 소스와 배포물에 포함하지 않는다. |
| S02·S11 | 네이버 시험 계정 한도 초과 거절·폐기·교체는 미시험이다. 운영에서 유료 키를 비활성화했다. |
| S03~06 | 403·429 등 오류를 자동 반복하지 않는다. JSON 가져오기와 렌더링은 허용된 데이터 모형만 사용한다. 단독 OSM 출력은 출처를 지도에 표시한다. 화면 암호는 PBKDF2-SHA256, 개별 salt, 600,000회로 비교한다. |
| S07~10 | 서버 인증 모드 전용으로 이 배포의 적용 범위 밖이다. |
| 기기 | macOS 데스크톱 Chrome 검증. 실제 사용자 아이폰 Safari의 전체 생성·저장·재열기는 남았다. |

실물 인쇄 색상, 현장 출입구, 범용 주소 자동화 전체 성공률은 아직 확정할 수 없다. 10곳의 출력을 검사할 때에는 조사자가 대상 객체를 지정했다.

실제 배포 출처의 첫 검사에서 새 탭 잠금 전 Overpass 호출 0건, 편집·실행 취소, 지도만 보기, JSON 복원 시 검수 초기화, ZIP 10개 다운로드·재개봉과 과거 ZIP 바이트 일치, 새로고침 재잠금을 확인했다. 실시간 수동 갱신에서 HTTP 502가 발생했을 때 이전 약도와 조회일이 유지됐다.

브라우저 두 탭에서 같은 저장 범위에 수동 갱신을 동시에 요청해 모의 공급자 호출 1건, 같은 성공 시각과 데이터 해시를 확인했다. 프로젝트 ID, 인쇄색, 개인 문구를 바꾼 경우 각각 다른 완성 파일 키가 생성됐다. tests/storage-browser.mjs로 재현할 수 있다. 실제 Pages에서는 기본 주소 입력·편집·다운로드가 가능한 상태이며 공용 공급자의 일시적 혼잡은 갱신을 지연시킬 수 있다.

운영 배포 012792b에서 2026-11-20 09:52~09:53 KST에 Chrome 157로 다시 검사했다. 다산74의 단지 객체와 주변 도로를 공개 Pages에서 Overpass에 POST로 조회했고, 변경된 데이터를 새 버전에 저장했다. 같은 실행에서 다운로드·복원·압축 재개봉도 통과했다. 별도 고정 응답 검사에서는 지리 자료가 같을 때 편집본을 유지하고, 변경 시 기존 버전과 편집한 하단 문구를 보존했으며, 429 응답은 한 번에 중단했다. 배포 파일 430개, 당시 Git 이력의 파일 객체와 배포 로그에서 이용 암호 원문과 검사 대상 토큰·비밀키 패턴은 검출되지 않았다.
